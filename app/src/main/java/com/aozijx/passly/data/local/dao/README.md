## 2. 行为红线（严格禁止事项）

* **绝对禁止使用** `@Update` 注解：严禁在 `History` / `Activity` / `Attachment` / `LookupIndex` /
  `KeyEnvelope` 接口中使用。
* **绝对禁止使用** `deleteById`：严禁在审计类表（`History` / `Activity`）中提供定点删除功能，以防篡改取证链。
* **禁止移除**：严禁未经架构评审擅自移除现有的安全校验逻辑。

## 3. 维护准则

* **不要做**：不要在 `Credential` 相关 DAO 中实现 `observeAll` 或返回大列表的方法（触发性能红线）。
* **不要做**：不要在非必要情况下将 `Flow` 暴露给高频变动的加密实体。
* **必须检查**：新增任何删除方法前，必须确认是否会破坏数据关联性（如导致孤立附件）。
* **已移除说明**：为了安全和性能，已从所有 DAO 中移除对原始加密 Blob 的模糊搜索支持。
