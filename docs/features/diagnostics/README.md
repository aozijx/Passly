# 诊断日志

状态：当前实现（代码核对：2026-10-18）。

诊断日志是“设置 → 数据管理”下的独立二级页面。数据管理页负责缓存/日志占用统计和清理入口；诊断页负责
查看、过滤、搜索、复制、保存和分享。两页不共享 ViewModel 状态。
