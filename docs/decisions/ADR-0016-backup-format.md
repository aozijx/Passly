# ADR-0016: 使用版本化加密备份容器

- 状态：Accepted
- 日期：未记录

## 背景

备份需要独立密码、格式识别、完整性校验以及快照和附件的共同传输。

## 决策

使用带 magic 和版本的二进制容器。Vault Snapshot 与可选图片/附件组成 ZIP 负载，再用备份密码经 Argon2id
派生的密钥执行 AES-GCM 加密。恢复码不用于备份。

## 后果

能拒绝错误密码、截断和未知版本，并完整往返附件。格式 v1 尚未把 KDF 算法及参数写入头；下一版本必须补齐自描述参数并认证头部。

## 备选方案

未采用明文 ZIP、与 Vault DEK 绑定的备份和只导出 JSON 的格式。
