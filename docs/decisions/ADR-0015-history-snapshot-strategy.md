# ADR-0015: 历史记录保存快照

- 状态：Accepted
- 日期：未记录

## 背景

仅保存字段差异会让恢复依赖完整变更链，版本迁移和损坏处理复杂。

## 决策

每个可恢复历史点保存该条目的完整加密内容快照：Profile、bundle、独立高敏密文、关联及附件引用。
Activity 只作为审计/展示事件，以版本关联内容重写，不承担恢复数据。访问与回收站生命周期事件不创建内容快照；
恢复历史创建新版本，不修改旧修订。

## 后果

恢复简单且单条历史自包含，代价是更多存储。需设置保留策略并在事务中创建快照与更新当前条目。

## 备选方案

未采用事件溯源和字段级 diff 链。
