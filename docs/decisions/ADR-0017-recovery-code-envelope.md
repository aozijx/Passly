# ADR-0017: 恢复码使用独立 Envelope

- 状态：Accepted
- 日期：2026-07-18

## 背景

用户可能失去生物识别或应用密码，但恢复能力不能保存可查看的明文恢复码，也不能与备份密码混用。

## 决策

身份认证后生成高熵恢复码，用 Argon2id 派生包装密钥并原子写入 Recovery Envelope。明文只展示一次；重新生成替换旧
Envelope；验证成功只用于解锁同一 Vault DEK。

## 后果

恢复方式独立且可撤销。用户丢失唯一展示的码后只能在仍可认证时重新生成；UI/ViewModel 必须及时清除敏感状态。

## 备选方案

未采用可查看恢复码、恢复码哈希仅验证而不能解锁、以及恢复码复用为备份密码。
