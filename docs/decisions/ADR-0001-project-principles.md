# ADR-0001: 项目原则

- 状态：Accepted
- 日期：未记录

## 背景

隐私保险库需要在安全、离线可用、可维护性和 Android 平台约束之间作长期取舍。

## 决策

Passly 采用安全优先、离线优先、清晰分层和可验证实现作为默认原则。安全声明必须对应威胁与测试；业务功能不依赖云端才可完成核心流程；边界通过
Domain 契约和 Mapper 明确表达。

## 后果

安全与数据完整性问题优先于便利性。新增抽象必须解决真实边界问题，不为形式上的“Clean Architecture”增加空壳层。

## 备选方案

未采用云端优先与快速功能堆叠方案，因为它们扩大数据暴露和长期维护成本。
