# ADR-0021: 采用可插拔的加密诊断系统

- 状态：Accepted
- 日期：2026-07-18

## 背景

旧日志工具允许自由文本、重复过滤器和直接文件导出，无法保证敏感信息在进入 Sink 前被删除；崩溃线程复用普通 writer
或临时访问 Keystore 还可能死锁。

## 决策

所有平台入口使用 `AppLog`，先转换为结构化事件并统一脱敏，再分发到 Android 与加密文件 Sink。每文件使用独立数据
密钥和逐记录 AES-GCM；Release 文件日志采用 24 小时显式诊断窗口。崩溃路径只使用启动期预加载的 emergency 密钥。

## 后果

日志不能包含任意业务明文，旧文件格式不兼容。安全导出必须新鲜认证并产生短生命周期明文文件；早期崩溃在密钥未就绪
时只能依赖脱敏 Android 日志。

## 备选方案

未继续维护 Logcat 兼容栈，未在崩溃线程调用 Keystore，也未写永久明文日志。
