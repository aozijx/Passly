# ADR-0019: 单 Vault DEK 与派生会话密钥

- 状态：Accepted
- 日期：2026-07-18
- 替代：[ADR-0003](ADR-0003-dual-dek.md)

## 背景

双 DEK 要求每种认证方式原子维护两组 Envelope，并显著增加解锁、轮换和擦除状态。当前实现实际维护一份
DEK，并用固定标签派生字段会话密钥。

## 决策

所有认证 Envelope 包装同一随机 Vault DEK。数据库口令来自该 DEK；字段加密密钥通过 HMAC-SHA256
与版本化域分离标签派生，并只在解锁会话中持有。

## 后果

Envelope 与状态机更简单，认证方式切换更可靠。DEK 泄露影响数据库与字段层，因此必须严格保护
DEK、缩短会话并保持域分离标签稳定；未来修改派生方式需格式迁移。

## 备选方案

未继续双 DEK，也未直接复用同一原始字节作为所有密码学用途。
