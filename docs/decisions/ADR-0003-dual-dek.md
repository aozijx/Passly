# ADR-0003: 采用双 DEK

- 状态：Superseded
- 日期：未记录
- 替代者：[ADR-0019](ADR-0019-single-dek-derived-session-key.md)

## 背景

早期设计希望用独立数据库 DEK 与字段 DEK 增加密钥分离，降低单密钥泄露的影响。

## 决策

分别维护 `DEK_DB` 与 `DEK_FIELD`，由认证凭据独立包装。

## 后果

该方案增加 Envelope 数量、认证迁移原子性和内存生命周期复杂度。当前代码并未实现双 DEK，而是单 Vault DEK
加域分离派生会话密钥，因此本决策被 0019 替代。

## 备选方案

当时未采用单 DEK 派生方案；后续基于可实现性与足够的域分离重新评估并采用。
